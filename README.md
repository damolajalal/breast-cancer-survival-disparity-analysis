Project Overview
This project investigates the critical survival gaps in breast cancer outcomes across different socio-economic regions. By synthesizing global health data, we identified a 0.93 correlation between early diagnostic timing and survival rates. This repository contains the Python scripts used for data engineering and the Power BI framework designed to help public health stakeholders move from "Diagnostic Inertia" to proactive screening.

Key Analytical Findings
The Survival Cliff: Survival rates drop from 87% in high-income nations to 28.3% in low-income regions.  

Preventable Risk: Approximately 30% of cases are linked to modifiable risk factors (e.g., obesity, lifestyle), providing a clear target for public health intervention.  

Diagnostic Gap: Late-stage diagnoses account for 40.5% of cases in underserved areas, directly driving the mortality-to-incidence disparity.  

Technical Stack
Python: Used for data cleaning, merging multi-source datasets, and performing correlation analysis.  

Power BI: Developed an interactive dashboard featuring DAX-powered "What-If" parameters to simulate survival improvements.
